Ayuda

Configurar en OBS

  1. En la app, haz clic en Examinar y selecciona tu save file o carpeta del emulador
  2. La app detecta el juego y genera una URL local (http://127.0.0.1:19876/overlay/...)
  3. Haz clic en Copiar URL
  4. En OBS Studio: click derecho en Fuentes > Agregar > Navegador
  5. Pega la URL copiada
  6. Establece ancho: 1920, alto: 1080
  7. Marca "Controlar el URL via JavaScript"
  8. Ajusta la posicion de los sprites en el Layout Editor de la app

Tip: La app monitoriza el save cada 500ms. Guarda en el juego y el overlay se actualiza solo.

Crear un proyecto

  1. Haz clic en el boton + de la barra lateral
  2. Escribe un nombre para el proyecto
  3. Haz clic en Examinar y selecciona tu archivo de guardado o carpeta del emulador
  4. Si seleccionas una carpeta, se abre un segundo dialogo para elegir el archivo save especifico
  5. La app detecta automaticamente la generacion y juego
  6. Selecciona un estilo de sprite
  7. Ajusta la posicion de los sprites en el Layout Editor
  8. Copia la URL de OBS y pegala en una fuente de navegador en OBS

Tip: La deteccion es automatica pero puedes forzar el juego manualmente en el selector.

Lectura de saves (PKHeX)

La app usa PKHeX (la libreria estandar de Pokemon) para leer los saves de todas las generaciones. Requiere .NET 8.0 Runtime instalado en el sistema.

Juegos soportados (Gen 1 - Gen 9):

  • Gen 1: Rojo, Azul, Amarillo (GB) - BGB, SameBoy, VisualBoyAdvance-M
  • Gen 2: Oro, Plata, Cristal (GBC) - SameBoy, VisualBoyAdvance-M
  • Gen 3: Rubi, Zafiro, Esmeralda, Rojo Fuego, Verde Hoja (GBA) - mGBA, VisualBoyAdvance-M
  • Gen 4: Diamante, Perla, Platino, HeartGold, SoulSilver (NDS) - DeSmuME, melonDS
  • Gen 5: Blanco, Negro, Blanco 2, Negro 2 (NDS) - DeSmuME, melonDS
  • Gen 6: X, Y, Rubi Omega, Zafiro Alfa (3DS) - Citra
  • Gen 7: Sol, Luna, Ultra Sol, Ultra Luna (3DS) - Citra
  • Gen 8: Espada, Escudo, Brilliant Diamond, Shining Pearl, Leyendas Arceus (Switch) - Yuzu, Ryujinx, Sudachi, Suyu
  • Gen 9: Escarlata, Purpura, Leyendas Z-A (Switch) - Yuzu, Ryujinx, Sudachi, Suyu

La deteccion del juego es automatica. Si falla, selecciona el juego manualmente en el selector de la izquierda.

Nota: Para Switch exporta el save con Checkpoint o JKSM desde la consola. Ryujinx guarda encriptado, usa Checkpoint para obtener una copia legible.

Estilos de sprite

Los sprites se cargan de %APPDATA%\nuzlocke-overlay\Recursos\Sprites\, organizados por generacion.

Descarga automatica: Al iniciar la app por primera vez sin sprites, pregunta si quieres descargarlos desde GitHub. Tambien puedes descargarlos desde Configuracion > Recursos.

Agregar estilos propios:

  1. Crea una subcarpeta en Recursos\Sprites\GenX\ (ej: MiEstilo)
  2. Pon los sprites PNG o GIF, nombrados por numero de Pokedex (ej: 025.png para Pikachu)
  3. Puedes usar subcarpetas para formas regionales (ej: shiny/, alola/)
  4. Selecciona el estilo en el selector de estilos de la app

Formatos de nombre soportados:

  • 025.png / 25.gif (numerico)
  • 025-pikachu.png (numerico + nombre)
  • 25-alola.png (formas regionales)
  • BT025.png (Battle Trozei)

Formato recomendado: PNG con fondo transparente, 96x96 o 128x128 px.

Rellenar slots vacios

Si tu equipo tiene menos de 6 Pokemon, puedes rellenar los slots vacios con un sprite placeholder.

  • Activa la opcion "Rellenar slots vacios" en la seccion Opciones
  • Se usara automaticamente el sprite por defecto del estilo (huevo o interrogacion)
  • Los placeholders se actualizan cuando cambias de estilo

Util para que el overlay siempre muestre 6 slots, incluso al principio de una run.

Personalizar nicknames

En la seccion "Estilo de Nickname" puedes configurar:

  • Fuente: Buscador con preview de todas las fuentes del sistema
  • Negrita / Cursiva: Estilo del texto
  • Color: Solido, degradado lineal o radial
  • Trazo: Borde del texto (exterior, centrado o interior)

Los nicknames son slots independientes. Puedes moverlos y redimensionarlos por separado de los sprites.

Layout Editor

Editor de layout en un lienzo de 1920x1080.

  • Arrastrar: Haz clic y arrastra para mover slots
  • Redimensionar: Arrastra las esquinas
  • Multi-seleccion: Ctrl+Click (seleccion individual), Shift+Click (rango), Ctrl+A (todos)
  • Snap: Guias magneticas de alineacion (checkbox "Snap")
  • Propiedades: Selecciona un slot para editar X, Y, W, H, Scale
  • Des/Hacer: Ctrl+Z / Ctrl+Shift+Z
  • Reset: Vuelve a la disposicion por defecto
  • Espaciado: Distribuye slots uniformemente
  • Alineacion: Izquierda, centro, derecha, arriba, abajo
  • Camara virtual: Boton "Cam" para previsualizar tu webcam sobre el layout. Util para posicionar sprites sin que tapen tu cara en OBS/Discord

Presets de layout

Los presets permiten guardar y reutilizar configuraciones de layout.

  • Guardar: Configura el layout y haz clic en "Guardar"
  • Cargar: Selecciona un preset de la lista y haz clic en "Cargar"
  • Eliminar: Selecciona un preset y haz clic en "Eliminar"

Util para cambiar rapido entre diferentes configuraciones de overlay.

Configuracion

Haz clic en el icono de engranaje para acceder a la configuracion:

  • Idioma: 6 idiomas disponibles (Espanol, English, Francais, Deutsch, Nihongo, Russkiy)
  • Modo segundo plano: La app se minimiza a la bandeja del sistema al cerrar (como Discord)
  • Recursos: Boton "Descargar Sprites" para obtener los sprites desde GitHub. Boton "Abrir carpeta" para gestionarlos
  • Social links: Acceso rapido a Twitch, YouTube, TikTok, Discord y GitHub

Actualizaciones

La app comprueba nuevas versiones al iniciar. Si hay una actualizacion:

  • Aparece un popup de notificacion con el boton "Descargar"
  • El Changelog se muestra al instalar una version nueva
  • Puedes usar "Omitir esta version" para no volver a verla

Las actualizaciones se descargan desde GitHub y se ejecutan automaticamente.

Solucion de problemas

"Sin equipo detectado"

  • Verifica que la ruta del save file sea correcta
  • Selecciona el juego manualmente en el selector de la izquierda
  • Guarda en el juego (Ctrl+S en el emulador) y espera 1-2 segundos
  • Para Gen 1-2: usa BGB o SameBoy para mejores resultados
  • Para Gen 3: usa mGBA (mejor compatibilidad que VBA-M)
  • Para Gen 4-5: usa DeSmuME o melonDS
  • Para Switch: exporta el save con Checkpoint o JKSM desde la consola
  • Consulta los logs en %APPDATA%\nuzlocke-overlay\logs\ para ver errores detallados

"Los sprites no aparecen"

  • Verifica que la carpeta Recursos/Sprites/ exista
  • Descarga los sprites desde Configuracion > Recursos > Descargar Sprites
  • Selecciona un estilo en el selector de estilos

"OBS muestra pantalla negra"

  • Verifica que la URL empiece con http://127.0.0.1:
  • Asegurate de que la app este abierta
  • Abre la URL en un navegador normal para verificar que funciona
  • En OBS, marca "Controlar el URL via JavaScript" en las propiedades del Browser Source

"El equipo no se actualiza"

  • La app detecta cambios cada 500ms automaticamente
  • Guarda en el juego (Ctrl+S) y espera 1-2 segundos
  • Algunos emuladores como Ryujinx guardan encriptado; usa Checkpoint en la consola para exportar una copia legible

"La camara virtual no funciona"

  • OBS: Herramientas > Iniciar Camara Virtual primero
  • Haz clic en "Cam" de nuevo para re-enumerar dispositivos
  • Permite el permiso de camara cuando el navegador lo pida
  • Si dice "No se encontro camara", verifica que OBS Virtual Camera este instalado

"La app no abre / crashea"

  • Borra %APPDATA%\nuzlocke-overlay\config.json y reabre la app
  • Verifica que .NET 8.0 Runtime este instalado
  • Revisa los logs en %APPDATA%\nuzlocke-overlay\logs\

"No encuentra .NET o PKHeX"

  • La app muestra un dialogo con boton "Descargar .NET" si falta el runtime
  • Instala .NET 8.0 Desktop Runtime desde dotnet.microsoft.com/download/dotnet/8.0
  • Reinicia la app despues de instalar .NET

Logs y depuracion

Los logs diarios se guardan en:

%APPDATA%\nuzlocke-overlay\logs\nuzlocke-YYYY-MM-DD.log

Busca lineas utiles para diagnosticar problemas:

  • [Watcher] PKHeX available: true/false — si PKHeX esta disponible
  • [PKHeX] Found X Pokemon — resultado de la lectura del equipo
  • [Camera] Devices found: — dispositivos de camara detectados
  • resolvedSavePath: — ruta final del save que se esta leyendo

Envia el log al desarrollador si necesitas soporte.
